Quick start

Up and running in under a minute

No VBA knowledge. No manual import. No running code by hand.

1. Grab the files

Clone the repo from GitHub, or download the folder you need — ExcellerApp for the desktop app, ExcelAddin for the Excel add-in.

2. Run the installer

Double-click install.bat. It compiles the add-in for you, installs it into Excel, and registers it to auto-load — you never touch the VBA editor.

3. Start asking

Excel opens with Exceller ready. Select data, click a button or press Alt+F8, and start asking questions.

Setup

Connect your Gemini API key

Exceller is powered by Google Gemini. Keys are free, stored locally, and never shared.

  1. Get a free key from Google AI Studio — aistudio.google.com/app/apikey
  2. Desktop app: set the GEMINI_API_KEY environment variable, or pass it to AIEngine(api_key=…)
  3. Excel add-in: run Exceller_Settings (Alt+F8) and paste your key — it's stored in the Windows registry
  4. That's it. Start chatting with your data 🎉
