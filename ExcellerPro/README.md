# Exceller Pro

**AI-Powered Excel Assistant**

Exceller Pro is a free Excel add-in that uses AI to help you work with data, formulas, and spreadsheets.

---

## Features

| Feature | Description |
|---------|-------------|
| AI Chat | Ask questions about your data in plain English |
| Data Analysis | Get insights, statistics, and recommendations |
| Fix Formula | Repair broken formulas with alternatives |
| Price Calculator | Get help with price calculations |
| Verify Formula | Check if formulas are correct |
| Create Table | Format data professionally |

---

## Installation

### Windows (Recommended)

1. Download the installer folder
2. Right-click `install.bat`
3. Select "Run as administrator"
4. Follow the prompts

### Manual Install

1. Open Excel
2. Press `Alt + F11`
3. Go to File > Open
4. Select `ExcellerPro.xlam`
5. Press `Alt + F8` to see commands

---

## First Time Setup

1. Get a free API key at https://makersuite.google.com/app/apikey
2. Press `Alt + F8`
3. Select `ExcellerPro_Settings`
4. Click Run
5. Enter your API key

---

## Usage

### Quick Start

1. Select data in Excel
2. Click a toolbar button
3. Get AI-powered help

### Commands

| Command | What it does |
|---------|--------------|
| Ask AI | Chat about your data |
| Analyze | Get data insights |
| Fix Formula | Repair broken formulas |
| Price Calc | Price calculation help |
| Verify | Check formula correctness |

### Example Prompts

**Data Analysis:**
- "Summarize this sales data"
- "Find any errors"
- "What trends do you see?"

**Formula Help:**
- "Write a formula to sum by month"
- "Fix this #REF! error"
- "Calculate price with discount"

**Price Calculations:**
- "Add 10% tax to column B"
- "Calculate total with bulk discount"
- "Look up price from product list"
